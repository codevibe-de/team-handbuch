Beschlossen in der Review-Runde am 5. November 2026:

1. Vor jedem Pull Request läuft `/code-review`. Gefundene Punkte werden behoben oder im PR begründet.
2. Pull Requests, die Claude überwiegend geschrieben hat, bekommen das Label „ai-assisted“.
3. Ein Review durch einen Menschen bleibt Pflicht, auch wenn `/code-review` nichts findet.
